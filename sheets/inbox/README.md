# 여기에 시트를 내려받아 둔다

작업을 시작하기 전에 **사용자가 직접 고친 구글 시트**를 이 폴더에 내려받고
아래 한 줄을 돌린다. 파일 이름은 아무래도 좋다 — 가장 최근 것을 집는다.

```
node tools/sheets-diff.js            # 무엇이 다른지 보기
node tools/sheets-diff.js --take     # 시트 쪽 수정을 가져오기
```

버전이 붙은 이름(`…-0.42.0.xlsx`)이 판마다 바뀌므로 이름으로 찾지 않는다.
자세한 절차는 `SHEET-FIRST.md`.

이 폴더의 .xlsx 는 저장소에 넣지 않는다(사람이 그때그때 내려받는 것일 뿐).
