# 판이 올라가도 그대로 읽힌다.
#
# 누가 읽나 — 센 것부터
#   ① 운영자 창 표 단에서 정한 문서 (0.51) — 서버를 다시 안 올려도 바꿀 수 있다

#   그러면 서버는 없어진 문서를 두드리며 401 만 돌려받는다. 0.45 부터 0.51 까지
#   여섯 판 연속으로 그랬다. 이제 그럴 때는 이 파일을 고치고 다시 배포할 것 없이
#   **운영자 창 → 표 → 시트 주소 붙여 넣고 '주소 저장'** 이면 된다.
#
