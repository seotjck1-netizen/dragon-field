# 표를 읽어 올 구글 시트.
#
# 여기 적힌 것은 문서 **아이디**다. 시트 이름(…0_42_0)이 바뀌어도 아이디는 안 바뀌므로
# 판이 올라가도 그대로 읽힌다.
#
# 누가 읽나 — 센 것부터
#   ① 운영자 창 표 단에서 정한 문서 (0.51) — 서버를 다시 안 올려도 바꿀 수 있다
#   ② 환경변수 SHEET_ID
#   ③ 이 파일
#
# ⚠ **문서 아이디가 판마다 바뀌고 있었다.** 새 문서를 만들어 올리면 아이디가 달라지는데,
#   그러면 서버는 없어진 문서를 두드리며 401 만 돌려받는다. 0.45 부터 0.51 까지
#   여섯 판 연속으로 그랬고, 0.59(19yz0jyl… → 1Jj67l_ut…) · 0.60(→ 1spbCZtQ…) ·
#   0.64(→ 1TJRJiOo…) 에서도 또 그랬다. 0.64.4 에는 드라이브에 같은 이름의 문서가
#   **다섯 개**나 쌓여 있었다(하루에 03:15 · 09:16 · 09:34 · 11:34 · 15:18).
#   시트는 계속 갈아 끼우고 있었는데, 서버는 03:15 짜리를 보고 있었다.
#   **판을 낼 때마다 새 문서를 만들면 매번 서버가 멎는다.**
#   그럴 때는 이 파일을 고치고 다시 배포할 것 없이
#   **운영자 창 → 표 → 시트 주소 붙여 넣고 '주소 저장'** 이면 된다.
#
#   다음부터는 새 문서를 만들지 말고 **같은 문서에 덮어쓰기로 가져오기** 를 쓰면
#   이 일이 아예 안 생긴다.
#
