## 본편에서 할 일 (수정안의 「바뀌는 것 한눈에」)

1. 장비 규칙 — 무기 대미지 = 5 + 덤 + 강화 · 방어구 다섯 부위 합 · 장신구는 옵션 줄만 · 등급이 덤 범위/줄 수/특수효과를 정한다.
2. 강화 C 규칙 — +10 이 끝, +7 부터 확률 급감, +8 부터 실패하면 한 단계 내려간다. 초월 강화 없앰.
3. 얻는 곳 — 모든 몬스터가 낮은 확률로 떨군다 + 상점 도박 상자 셋. **세트는 정해진 몬스터만**(답 6).
4. 필드 실시간 전투를 기본으로(잡몹) — 사거리(검 1 · 지팡이 3 · 활 4칸), 싸우는 중에도 걷기, **350ms 박자**(답 3), Shift 빨리 보기 없음.
   보스 · 고룡은 전투 화면 + 돌입 소리(답 4). `?field=1` 미리보기 코드가 출발점이다.
5. 세이브 새로 시작(답 1) · 판 번호(답 2).
6. 다 바꾼 뒤 밸런스 대시보드 · `tools/synergy.js` 로 다시 잰다(0.80.03 의 트리 값은 지금 전투 화면 · 지금 장비에 맞춘 것이다).
