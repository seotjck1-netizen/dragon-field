# 장비를 하나씩 입히는 그림 (0.70.26 미리보기)

> 사용자가 준 **다 입은 그림**(용사·사냥꾼·마법사)에서 시작해,
> **벗은 몸(기본 티·바지)** 위에 장비 칸을 하나씩 얹는다.
> 다 얹으면 준 그림과 **점 하나 다르지 않다.**

## 돌리는 순서

```bash
python3 tools/ref-cut.py        # 준 그림의 체크무늬 배경 걷기 → art/reference/<직업>_ref_cut.png
node tools/base-bake.js         # 벗은 몸 굽기(tools/art-base.js) → art/parts/<직업>/base.png
python3 tools/ref-compose.py    # 칸별로 가르고(tools/ref-parts.py) 하나씩 입히기 → art/parts/<직업>/state_*.png
node tools/gear-preview.js      # 미리보기 → art/preview/gear-<직업>.png · gear-all.png
```

필요한 것: `opencv-python-headless`, `numpy`, `scipy`, `Pillow`, `playwright`(devDependencies).
게임을 돌리는 데는 필요 없다.

## 칸 ↔ 그림 조각

| 칸 | 용사 | 사냥꾼 | 마법사 |
|---|---|---|---|
| 갑옷 | 파란 튜닉·사슬·바지 | 초록 튜닉·가죽 조끼·기운 바지 | 파란 로브 |
| 어깨 | 붉은 망토·깃·어깨받이 | 털 어깨받이 | 붉은 망토·깃·사슬 |
| 장갑 | 팔보호대·장갑 | 팔보호대·장갑 | 반장갑 |
| 신발 | 쇠코 장화 | 끈 장화 | 쇠 신 |
| 벨트 | 허리띠·어깨끈·주머니 | 허리띠·엇갈린 끈·주머니·칼·밧줄 | 허리띠·어깨끈·주머니·책 |
| 무기 | 칼 | 활 + 화살통(등 뒤) | 수정 지팡이 |
| 투구 | — | — | — (머리띠·깃털·서클릿은 머리에 붙어 있다) |

## 어떻게 가르나 (tools/ref-parts.py)

1. **대강** — 칸마다 다각형 + 색 조건을 앞에서부터 적용한다. 먼저 맞은 것이 이긴다.
2. **테두리에 맞추기** — 검은 테두리 안쪽의 작은 덩어리는 통째로 한 칸이 된다.
   큰 덩어리는 맞추지 않는다 — 짙은 색끼리(짙은 바지·짙은 망토 안감)는 한 덩어리로 이어지기 때문이다.
3. **되돌리기** — 갑옷 속의 망토 빨강, 허리띠 속의 튜닉 파랑은 제 칸으로 돌린다.
4. **선 나누기** — 두 부품 사이의 검은 선은 **앞 부품의 것**이다. 허리띠를 벗기면 허리띠 테두리도 사라진다.

## 어떻게 입히나 (tools/ref-compose.py)

* 뒤 → 앞: 망토 안감 → 벗은 몸 → 칸별 층(직업마다 앞뒤가 다르다) → 무기 쥔 손 → 머리.
* **가려 있던 자리 메우기** — 허리띠 밑의 튜닉, 칼 밑의 망토. 둘레에서 가장 많은 색으로 판판하게 칠한다.
  메운 자리는 **가리던 것이 없을 때만** 그린다.
* **갑옷을 입으면 티·바지는 통째로 감춘다** — 벗은 옷이 갑옷보다 넓으면 가장자리로 삐져나온다.
* **맨손** — 장갑 낀 손을 살색 사다리로 다시 칠한다(손 모양·자세는 준 그림 그대로).
* 새로 드러난 가장자리에만 테두리를 두른다.

## 한계 — 알고 쓸 것

* **칸마다 모양이 하나다.** 준 그림에 있는 장비 한 벌만 있다. 같은 칸의 다른 아이템(가죽 갑옷·판금 갑옷)은
  아직 같은 그림이다 — 색을 바꿔(틴트) 구분하거나, 아이템 그림을 따로 받아야 한다.
* 가려 있던 자리는 **지어낸 것**이다. 허리띠만 벗긴 튜닉의 허리는 판판한 한 색이다.
* 자세가 하나다(서 있는 앞모습). 걷기·공격 그림은 아직 없다.

# 희귀도별 새 장비 그림 (0.70.26 둘째 판)

> 위의 "준 그림을 갈라 입히기" 는 **한 칸에 한 벌**뿐이었습니다. 이번에는 기본 몸
> (사용자가 준 티·반바지 견본 넷 — `docs/ANIM.md`) 위에 **희귀도 다섯 단계를 새로 그렸습니다.**

## 돌리는 순서

```bash
python3 tools/gear-art.py            # 장비 그림 → art/gear/<몸>/<칸>_<등급>/ · art/gear/weapons/
python3 tools/body-anim.py           # 기본 몸 동작
python3 tools/body-anim.py --gear    # 장비를 입힌 동작 → art/anim/gear/<몸>_<등급>/
python3 tools/body-anim.py --gear-meta   # (몸마다 따로 구웠을 때) 동작 목록을 한 파일로
python3 tools/gear-showcase.py       # art/preview/gear-items.png · gear-lineup.png · gear-anim.html
```

## 등급 — 게임의 희귀도 이름·색 그대로

| 등급 | 재질 | 눈에 띄는 것 |
|---|---|---|
| 일반 | 누빈 천 · 거친 가죽 | 쇠붙이 없음, 너덜한 단 |
| 고급 | 무두질한 가죽 · 쇠 버클 | 초록 덧천, 바늘땀 |
| 희귀 | 강철 판 · 파란 기사 천 | 은 리벳, 파란 보석, **짧은 망토** |
| 영웅 | 검은 강철 · 금 테 | **보랏빛으로 빛나는 룬**, 뿔 투구, 긴 보라 망토, 몸 둘레 반짝임 |
| 전설 | 붉은 용비늘 · 금 | **붉게 타는 용안 보석**, 날개 투구, 긴 붉은 망토, 불티 |

이름은 `src/data/items.json` 을 따랐습니다(천 옷 · 가죽 갑옷 · 기사 갑옷 · 룬 갑옷 · 용비늘 성갑 …).
그 등급의 아이템이 게임에 아직 없는 칸은 도감에 **예시** 로 표시했습니다.

## 어떻게 몸에 맞추나

* 몸마다 몸통·팔·다리·머리 **윤곽을 재어**(`Geo`) 그 윤곽을 따라 판을 그린다 — 네 몸 모두에 맞는다.
* 장비는 몸 조각에 **덧칠**된다(body-rig 의 `gear`): 갑옷·허리띠·목걸이 → 몸통, 소매·장갑 → 팔,
  바지·신발 → 다리, 투구 → 머리. 그래서 **몸과 똑같이 움직인다.**
* 따로 도는 층: **어깨받이**(윗팔을 반쯤 따라 돈다), **망토**(몸 뒤, 목에 매달림).
* 장갑은 손 그림을 **재질 색으로 다시 칠한다** — 손가락 모양이 그대로 살아 있다.
* 무기(칼·활·지팡이 × 5)는 제 틀에 따로 그리고 손잡이 좌표로 손에 쥐인다.

## 한계

* 앞모습 하나다(왼쪽은 뒤집기).
* 같은 등급이면 같은 모양이다 — 같은 등급 안의 아이템을 가르려면 색을 바꾸거나 그림을 더 그려야 한다.
* 영웅·전설의 반짝임·불티는 **한 벌을 다 입었을 때** 붙는 효과로 넣었다(미리보기). 게임에서는
  세트 효과로 쓸지, 아이템 하나에 붙일지 정해야 한다.
