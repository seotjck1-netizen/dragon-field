# 포이노(poinolunch) ↔ 드래곤 필드 — 랭킹 · 점수 연동 분석

> 2026-11-21 · 0.80.27 기준. 사용자 물음: 「poinolunch.vercel.app 에 드래곤필드를 올려놨는데, 저 사이트에서 각종 정보를 읽어서 같이 랭킹 등록 및 점수가 연동되게 가능한지」.
> 살아 있는 사이트(poinolunch.vercel.app)는 이 세션의 네트워크 규칙에 막혀 직접 열지 못했다. 대신 사이트의 원본 저장소
> `seotjck1-netizen/poinolunch`(2026-11-21 푸시)를 읽기 전용으로 붙여 코드를 읽었다.

## 1. 지금 어떻게 붙어 있나

| 무엇 | 지금 |
|---|---|
| 포이노 | React + Vite(Vercel). 데이터는 **Firebase Realtime Database**(`poinolabs-default-rtdb`) |
| 포이노 사람 | 비밀번호 없는 **닉네임**(`localStorage['dice_user']`) + Firebase **익명 로그인**. 이름은 스스로 고른다 |
| 포이노 랭킹 | 게임마다 `leaderboards/<게임>/<닉네임>` = `{ score }` · `{ timeMs }` · `{ level, playtime }`(블러드 오멘). 게임 목록의 「BEST」 배지(`App.jsx` gameBests)와 게임 화면 🏆(GameShell)이 읽는다 |
| DB 규칙 | 읽기 = 로그인한 누구나, `leaderboards` 쓰기 = **로그인한 누구나**(익명 포함). 관리자 경로만 이메일 계정으로 잠겼다 |
| 드래곤 필드 | `DragonFieldGame.jsx` — 「게임 시작」 이 `https://dragon-field.onrender.com/` 으로 **페이지를 통째로 옮긴다**(iframe 이 아니다 — 우리 게임이 남의 틀 안에서는 저장 · 로그인을 막으므로). 돌아오기는 뒤로가기 + `sessionStorage['return_tab']`. 「계정은 게임 안에서 따로 만듭니다(포이노 프로필과 별개)」 |
| 오늘의 게임 | 드래곤필드는 후보에서 빠져 있다(poinolunch CLAUDE.md · `plans.js` 의 `noDaily`) |

**지금은 아무것도 이어져 있지 않다** — 닉네임도 점수도 서로 모른다. 두 사이트는 주소(origin)가 달라서
드래곤 필드가 포이노의 `localStorage` · `sessionStorage` 를 읽을 수 없다. 넘길 수 있는 길은 ① 주소에 실어 보내기 ② 서버끼리 주고받기 둘뿐이다.

## 2. 된다 — 권하는 짜임

```
포이노 「게임 시작」 ──(주소 #poino=닉네임)──▶ 드래곤 필드(게임)
                                              │ 로그인한 뒤 한 번: 「포이노 ○○ 과 연결할까요?」 → 서버에 적음
                                              ▼
                                     드래곤 필드 서버(Render)
                                              │ 레벨 · 탑 · 결투장이 바뀔 때(몇 분에 한 번으로 묶어)
                                              ▼
                     Firebase  leaderboards/dragonfield/<닉네임> = { level, cls, tower, arena, ts }
                                              ▲
포이노 게임 목록 배지(Lv35) · 🏆 순위 ─────────┘ (지금 다른 게임과 같은 길)
```

1. **연결(한 번)** — 포이노가 `DRAGON_FIELD_URL + '#poino=' + encodeURIComponent(닉네임)` 으로 보낸다.
   게임은 로그인 뒤 그 이름을 보여 주고 **한 번 묻고**(「포이노 ○○ 와 연결」) 서버의 계정에 `poino` 로 적는다.
   포이노 이름 하나에는 드래곤 필드 계정 하나만(먼저 연결한 쪽). 끊기 · 바꾸기는 설정 창에서, 운영자는 운영자 창에서.
   - 포이노 닉네임으로 **자동 로그인은 하지 않는다** — 포이노 이름에는 비밀번호가 없어 남의 이름을 치면 남의 계정에 들어가게 된다.
2. **점수는 서버가 올린다** — 우리 규칙(「랭킹의 레벨 · 직업은 서버 세이브에서만」 · 「운영자는 랭킹에 안 오른다」)과 같은 믿음.
   게임(브라우저)이 Firebase 에 직접 쓰면 콘솔 한 줄로 Lv.99 를 올릴 수 있다.
   - 서버는 의존성 없이 Firebase **REST** 로 쓴다: 전용 이메일 계정으로 로그인(identitytoolkit) → `PUT …/leaderboards/dragonfield/<닉네임>.json?auth=<토큰>`.
     계정 · 비밀번호는 Render 환경변수(`POINO_FB_EMAIL` · `POINO_FB_PASSWORD` · `POINO_FB_API_KEY` · `POINO_FB_DB_URL`) — 저장소에 넣지 않는다.
   - 올리는 값: 레벨 · 직업(서버 세이브) · 이번 주 탑 최고 층 · 결투장 점수 · 시각. 너무 자주 쓰지 않게 계정마다 몇 분에 한 번.
3. **Firebase 규칙 한 줄**(포이노 쪽, 콘솔에서 게시) — `leaderboards/dragonfield` 쓰기는 그 전용 이메일만:
   `"leaderboards": { "dragonfield": { ".write": "auth != null && auth.token.email == '<전용 이메일>'" } }`.
   이것이 없으면 익명 접속자 누구나 드래곤 필드 점수를 쓸 수 있다(지금 다른 게임들은 그렇다).
4. **포이노 화면** — `DragonFieldGame.jsx` 에 🏆 순위(블러드 오멘처럼 `leaderboards/dragonfield` 구독, 레벨 · 탑 · 결투장 갈래),
   `App.jsx` gameBests 에 `Lv35` 배지 한 줄. 「계정은 따로」 안내는 「연결하면 순위가 포이노에도 올라갑니다」로.

## 3. 다른 길(권하지 않음)

| 길 | 왜 아닌가 |
|---|---|
| 포이노가 드래곤 필드 서버 `/api/rank` 를 바로 읽기 | 이미 CORS `*` 라 읽을 수는 있다. 그러나 Render 가 잠들어 있으면 🏆 를 누를 때 **최대 1분** 기다린다. 이름도 게임 안 이름이라 포이노 닉네임과 안 맞는다 |
| 게임(브라우저)이 Firebase 에 직접 쓰기 | 위 2 — 값을 믿을 수 없다 |
| 포이노 닉네임으로 드래곤 필드 계정 자동 생성 · 로그인 | 위 1 — 포이노 이름에는 비밀번호가 없다 |
| iframe 으로 넣고 postMessage | 우리 게임이 틀 안에서는 저장 · 로그인을 막는다(보안 경고). 페이지 이동이 맞다 |

## 4. 할 일 · 어림

| 어디 | 일 | 어림 |
|---|---|---|
| 드래곤 필드 | `#poino=` 받기 · 연결 묻기(로그인 뒤 한 번) · `/api/poino/link` · 설정 창 끊기 · 운영자 창 보기 | 작다 |
| 드래곤 필드 서버 | `server/poino.js` — Firebase REST 로그인 · 묶어 쓰기(몇 분에 한 번) · 운영자 제외 · 환경변수 없으면 꺼짐 | 작다 |
| 드래곤 필드 시험 | 가짜 Firebase(로컬 HTTP)로 — 연결, 한 이름 한 계정, 운영자 제외, 키 없으면 안 씀 | 작다 |
| 포이노 | `DragonFieldGame.jsx`(주소에 닉네임 · 🏆) · `App.jsx` 배지 · `database.rules.json` 한 줄 | 작다 |
| 사용자 | Firebase 콘솔: 전용 이메일 계정 만들기 · 규칙 게시. Render: 환경변수 넷 | — |

두 저장소를 함께 고치므로 순서가 있다: ① 드래곤 필드 서버(연결 · 올리기, 키 없으면 꺼짐) → ② Firebase 계정 · 규칙 · Render 환경변수 →
③ 포이노 화면. ①만 먼저 올려도 아무것도 깨지지 않는다(키가 없으면 안 쓴다).

## 5. 정할 것

1. 포이노 순위에 무엇을 보일까 — 레벨(추천) · 이번 주 탑 층 · 결투장 점수 · 보스 타임어택 중 무엇을, 몇 갈래로.
2. 연결은 「로그인 뒤 한 번 묻기」(추천) 인가, 설정 창에서 직접 하기인가.
3. 포이노 쪽 코드도 이 세션에서 고칠까(저장소를 붙여 두었다 — 지금은 읽기만), 포이노 작업 세션에서 할까.
