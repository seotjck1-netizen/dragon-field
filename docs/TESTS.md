### ⚠ 서버 시험은 진짜 계정 폴더를 **절대** 안 건드린다 (0.70.25)

0.70.23 까지의 서버 시험(`/tmp/srvup.sh`)은 돌 때마다 `rm -rf server/data` 를 했습니다.
작업 공간이 따로 떨어진 그릇일 때는 괜찮았지만, 시험이 저장소에 들어온 지금
그대로 옮겨 오면 **운영 서버에서 `npm test` 한 번에 모든 계정이 사라집니다.**

그래서 서버가 쓸 폴더를 바꿀 수 있게 했고(`POINO_DATA_DIR` · `POINO_CONTENT_DIR`,
비워 두면 예전 그대로), `tests/lib/server.js` 가 임시 폴더에 따로 띄운 뒤 지웁니다.
`accounts-mail-rank` 의 마지막 줄이 **진짜 계정 파일에 시험 계정이 안 들어갔는지**를 봅니다.

```bash
bash tests/run.sh              # 전부
bash tests/run.sh depth tiles  # 골라서
```

결과는 `/tmp/testout/<이름>.txt` 에 남습니다(그건 버려도 되는 것입니다).

## 작업 공간이 비워진 다음 (연장 되살리기)

```bash
npm install          # playwright · esbuild 를 되살린다
bash tests/run.sh    # 도는지 본다
```

`dependencies` 는 **비어 있습니다** — 게임 자체는 바깥 것을 하나도 안 씁니다.
`devDependencies` 에 있는 둘은 **만들 때만** 쓰는 연장입니다:

| 연장 | 어디에 쓰나 |
|---|---|
| `playwright` | 시험을 띄우고, `tools/gen-assets.js` 가 SVG 를 PNG 로 굽는다 |
| `esbuild` | `npm run build` — 단일 파일 HTML 로 묶는다 |

> 0.70.24 에 작업 공간이 비워졌을 때, 둘 다 `package.json` 에 안 적혀 있어서
> 무엇을 어느 판으로 깔아야 하는지 **다시 알아내야 했습니다.**
> 적어 두면 `npm install` 한 줄입니다.

## 크로미움 판 맞추기

이 그릇에는 크로미움이 **미리 깔려 있습니다**(`/opt/pw-browsers`, 판 1194).
playwright 는 제 판에 맞는 크로미움만 찾으므로, 새로 깔면 이런 것이 뜹니다:

```
Executable doesn't exist at /opt/pw-browsers/chromium_headless_shell-1243/...
```

**크로미움을 새로 내려받지 마세요.** 이 그릇에서는 막혀 있습니다.
대신 **playwright 쪽을 맞춥니다**:

```bash
npm install playwright@1.56.0 --no-save    # 1.56 이 크로미움 1194 를 쓴다
```

맞추면 시험만이 아니라 `tools/gen-assets.js`(그림 굽기)도 함께 삽니다.

## 시험을 새로 쓸 때

### ① 재는 연장을 먼저 의심하라

0.70.23 에 앞뒤를 재는데 네 방향이 전부 `0픽셀` 로 나왔습니다.
"다 가려졌다" 로 읽힐 뻔했는데, 틀린 것은 **자**였습니다 —
카메라는 `render()` 안에서 제자리를 잡는데 그리기 **전에** 재고 있었습니다.

> **0 은 '없다' 와 '못 봤다' 를 구별하지 않습니다.**
> 0 이 나오면 고치기 전에 **재는 자리부터** 찍어 보세요.

### ② 시험이 정말 잡는지 **되돌려 보라**

0.70.24 에 표지판 글자가 보이는지를 글자 전체의 픽셀 수로 쟀습니다.
일부러 버그를 되살려 보니 **그대로 통과**했습니다(560 → 326픽셀).
나무가 앞머리만 덮었는데 합으로는 여전히 "보인다" 였던 것입니다.

양끝을 따로 세도록 고치니 307 → 73 으로 떨어져 잡혔습니다.

> **새 시험은 반드시 한 번 실패시켜 보세요.**
> 실패시켜 본 적 없는 시험은 지키는 것이 아니라 **장식**입니다.

### ③ 규칙을 베껴 쓰지 마라

시험이 게임의 규칙을 다시 적어 두면, 규칙이 바뀔 때 시험도 같이 바뀌어
**둘 다 틀렸는데 통과**합니다. 코드에서 읽으세요
(`VARIANTS_FOR_TEST`, `pickVariantForTest` 가 그래서 있습니다).

### ④ 숫자가 아니라 성질을 재라

"퀘스트 경험치가 2000~3000" 같은 시험은 값을 조정할 때마다 깨집니다.
**"이웃한 것들 사이에 있다"** 를 재세요.
