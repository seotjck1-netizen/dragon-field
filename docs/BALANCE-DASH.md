# 밸런스 대시보드 — 사람처럼 키워 보는 흉내 (0.70.39)

> claude.ai 의 대시보드 "드래곤 필드 밸런스" 가 쓰는 숫자와 페이지를 만드는 법.

## 무엇을 보여 주나

- **큰 숫자 다섯** — Lv.45 · Lv.50 · 룬 한 벌 +10 · 룬 한 벌 +15 까지 걸리는 시간, 모은 경험치 가운데 보스 몫.
  저마다 **0.70.38 값으로 돌린 시간**(몇 배 느려졌나)과 사용자가 0.70.38 에서 잰 값을 곁들인다
- **시간에 따른 레벨** — 직업 셋 + 고른 직업의 0.70.38(회색 선) + 바꾼 값(붉은 점선) + 사용자가 잰 값(별표)
- 레벨에 따른 시간 · 레벨에 따른 경험치(필요 vs 1분에 번) · 경험치는 어디서 오나(잡몹 · 보스 · 의뢰 몫)
- **모든 수치 비교** — 레벨 · 전투력 · 공격력 · 체력 · 방어력 · 강화 · 분당 경험치 · 골드 · 보스 잡은 수 · 상대 전투력 ·
  재료를 처음 대비 배수나 값 그대로 한 그림에 겹친다(가로축 시간 · 레벨)
- 항목별 여덟 장 — 장비 한 벌과 강화(한 벌 띠) · 전투력(구간마다 오른 양) · 공격력 · 골드 · 무엇을 잡고 있나 ·
  보스 잡은 수와 의뢰 · 사냥터별 몬스터 세기 · 재료와 보석 모은 양
- 레벨별 표 — 그 레벨에 닿은 시각 · 0.70.38 로는 언제 닿았나 · 하던 일 · 장비 · 전투력
- **수치 바꿔 보기** — 경험치 곡선 · 눈금 · 레벨 차 천장 · 보스 다시 서기 · 골드 · 떨어지는 것 · 강화 값 · 보석 값 ·
  사냥 방식(전투 보는 속도 · 걷는 시간 · 지면 잃는 시간 · 최소 승률 · 흉내 낼 시간). 빠른 설정:
  지금 게임 값 / 0.70.38 값 / 0.70.38 + 관리자 리젠(보스 20초 · 건너뛰기) / 보스 경험치 절반 / 보스 3분
- 위의 **처음 5시간 · 전부(24시간)** 단추로 시간 축을 고르고, **0.70.38 겹쳐 보기** 로 회색 선을 켜고 끈다

## 숫자를 만드는 법

```bash
node tools/balance-dash.js            # 지금 표(src/data)로   → dist/balance/*.json   (2분 남짓)
node tools/balance-dash.js sheets     # sheets/*.csv(구글 시트에서 받아 온 것)로
node tools/balance-page/run.js        # 흉내를 터미널에서 — 지금 값과 0.70.38 값
node tools/balance-page/run.js '{"보스 3분":{"BOSS_RESPAWN_S":180}}'
bash tools/balance-page/build.sh      # 대시보드 페이지 → dist/balance/page.html · page.doc.json
```

`balance-dash.js` 는 게임의 **진짜 전투 계산기**(src/systems/CombatSystem.js)로 **전투 결과 표**를 만든다 —
직업 셋 × 레벨 1~50 × 장비 한 벌 여섯 가지 × 강화 0 · 4 · 7 · 10 · 12 · 15 마다, 사냥터의 잡몹과 보스 전부와 12판씩
(씨앗 1~12 — 같은 표면 늘 같은 결과). 몸(장비 · 강화 · 스킬)은 tools/balance.js 의 statsOf 를 그대로 쓰고,
스킬 순서는 레벨마다 balance.js 의 후보(PLANS)를 모두 돌려 **가장 많이 이기는 것**을 쓴다.
게임의 값(경험치 곡선 · 레벨 차 천장 · 보스 다시 서기 · 강화 값 …)은 formulas.js · MapSystem.js 에서 읽어
`consts.json` 에 적는다. 바꾸기 전 값(`OLD_GAP_MAX` · `OLD_BOSS_RESPAWN_S`)도 거기 있다.

흉내(`tools/balance-page/sim.js`)는 대시보드 페이지 안에서도 그대로 돈다 — 지금 값으로 한 번, 0.70.38 값으로 한 번,
값을 바꾸면 한 번 더. 직업 셋 × 24시간이 0.5초 남짓이다. 페이지는 `tools/balance-page/` 의 다섯 조각
(head · body · sim · calc-tail · ui)을 build.sh 가 이어 붙인 것이고, 대시보드의 `files/index.html` 문서로 올린다.

만든 파일을 대시보드에 올리는 일은 Claude 가 한다 — 시트를 고친 뒤 **"밸런스 대시보드 다시 계산해줘"** 라고 하면
시트를 받아 이 도구를 돌리고 새 파일로 바꿔 끼운다.

> ⚠ 0.70.39 를 만드는 동안 작업 공간이 한 번 통째로 비워졌다. 대시보드 페이지는 대시보드에 올려 둔 것에서 그대로 되살렸고
> (한 글자도 다르지 않다), 이 도구는 올려 둔 자료와 **같은 값이 나오는지 견주며** 다시 썼다 — 사냥감 · 한 벌 · 물건 · 의뢰 ·
> 상수 표는 같고, 전투 표는 스킬 순서 고르는 법을 위처럼 정하면서 몇 레벨(용사 24~26 · 사냥꾼 몇 레벨)이 달라졌다.
> 떨어지는 것 표는 같은 물건이 두 줄인 몬스터(강화된 동굴 박쥐 · 강화된 버섯 …)를 **더해서** 적는다(게임은 두 줄을 다 굴린다 —
> 예전 도구는 뒷줄만 적었다).

## 흉내의 규칙 (대시보드 '어떻게 쟀나' 에도 있다)

| 무엇 | 규칙 |
|---|---|
| 1분마다 | 들어갈 수 있는 곳(구간 문 보스 · 성 Lv.25 · 지하감옥 Lv.40)에서 분당 경험치가 가장 많은 일. 만렙이면 골드 · 보석 |
| 잡몹 | 한 마리 = 전투 연출 ÷ 보는 속도(기본 4배, Shift) + 걷기 5초 + 질 확률 × 30초. 평균 승률 80% 넘는 곳만 |
| 보스 | 이길 확률 25% 넘으면 되풀이해 잡는다. 지면 곧바로 다시(진 시간만 잃음), 이기면 다시 설 때까지 같은 맵 잡몹을 잡거나 웨이포인트(오가는 데 20초씩)로 더 나은 사냥터에 다녀온다. 다음 구간 문 보스는 15% 넘으면 먼저 |
| 의뢰 | 장비를 주거나 2분 안에 끝나거나 보상이 그 시간 사냥의 절반은 될 때. 모으라는 재료는 강화에 쓰지 않고 남긴다 |
| 마을 | 10분마다(더 좋은 한 벌을 살 돈이 생기면 곧바로) 30초. 사고 · 강화 · 초월을 한꺼번에 |
| 장비 | 다음 한 벌이 **지금 입은 만큼 강화했을 때** 더 세면 산다. 강화가 따라잡을 때까지는 옛 한 벌을 입는다. 부위마다 강화 수치를 따로 기억한다(룬 한 벌 → 룬+인장으로 넘어가도 남는다) |
| 강화 | 가장 낮은 부위부터. 재료가 모자라면 약초를 사서 연금술사에게 바꾼다(약초 5 → 마력석 1, 마력석 10 → 악마의 핵 1) |
| 초월 | 더 얻을 한 벌이 없을 때만. 남는 보석 셋을 하나로 바꾸고, 그래도 모자라면 보석 노인에게서 산다 |
| HP | 매 판 가득으로 시작(실제로는 앞 싸움의 HP 가 남는다) |

## 0.70.39 에서 잰 것

사용자가 0.70.38 에서 잰 값: 한 시간이면 Lv.45 · 모든 장비 +10, 두 시간이면 +15 한 벌.
흉내는 보통 사람(보스 1분 · 4배속)으로 Lv.45 1.4~1.9시간, **관리자 리젠처럼 보스를 20초마다 · 전투를 건너뛰면
52분~1.4시간** — 사용자가 잰 값과 맞는다. 경험치의 80~85%(용사 · 사냥꾼)가 보스에서 나왔다.

그래서 0.70.39 에서 **레벨 차 경험치 천장 2배**(formulas.js `EXP_GAP_MAX`) · **보스 5분**(MapSystem.js
`BOSS_RESPAWN_MS`)으로 묶었다(tests/balance.js 가 못 박는다):

| 직업 | Lv.45 | Lv.50 | 룬 +10 | 룬 +15 | 보스 몫 |
|---|---|---|---|---|---|
| 용사 | 1.9 → **6.1시간** | 5.7 → **22.3시간** | 59분 → 1.3시간 | 4.2 → **9.5시간** | 85 → **32%** |
| 사냥꾼 | 1.9 → **5.4시간** | 5.5 → **18.6시간** | 40분 → 57분 | 2.7 → **5.3시간** | 80 → **27%** |
| 마법사 | 1.4 → **4.3시간** | 3.8 → **10.2시간** | 38분 → 1.0시간 | 3.0 → **5.7시간** | 3 → 2% |

- **룬 +10 은 거의 그대로** — 룬 장비 대부분과 골드 50만이 의뢰 보상으로 오기 때문이다(보스와 상관없다).
- **마법사가 두 배 빠르다** — 보스를 거의 안 잡고 잡몹(지하감옥)만으로 큰다. 천장 · 보스 값으로는 안 잡히는 차이다.
- 보스 경험치 눈금을 0.5 → 0.25 로 더 줄이면(대시보드 빠른 설정) 용사 Lv.45 7.2시간 · 사냥꾼 6.1시간 · 마법사 4.8시간.
