# 기본 몸 동작 (0.70.26 미리보기)

> 사용자가 준 **기본 몸 견본**(티·반바지 — 깨끗한 차림·거친 차림, 남녀)에 뼈대를 넣어
> 대기 · 걷기 · 달리기 · 점프 · 베기 · 주먹 · 활쏘기 · 마법 · 맞기 · 쓰러짐 · 승리를 만든다.
> 아직 게임에 넣지 않았다(미리보기).

## 돌리는 순서

```bash
python3 tools/ref-cut.py base_clean base_rugged   # 체크무늬 배경 걷기
python3 tools/body-split.py                       # 한 장에 둘 → 한 사람씩 768×1024 (m1·f1·m2·f2)
python3 tools/body-rig.py --debug                 # 몸을 조각으로 나눈 모습 → art/anim/<몸>/_parts.png
python3 tools/body-anim.py                        # 모든 동작 굽기 → art/anim/<몸>/<동작>_<n>.png (320×320) · anims.json
python3 tools/body-anim.py --html                 # 움직이는 미리보기 → art/preview/anim.html
S=120 python3 tools/body-anim.py --sheet          # 한 장 확인 → art/preview/anim-sheet.png
```

무기(칼·활·지팡이)는 장비 층 미리보기(`docs/GEAR-ART.md`)가 준 그림에서 오려 둔 것을 쓴다 —
`python3 tools/ref-compose.py` 를 먼저 돌려 `art/parts/<직업>/labels.png` 가 있어야 한다.

## 지키는 규칙 — 몸·다리 비율은 그대로

> 뼈 길이(sx·sy)를 바꾸지 않는다. `tools/body-rig.py` 가 바꾸려 하면 멈춘다.

처음 판은 앞모습에서 무릎을 드는 것을 **다리를 줄여서** 흉내 냈다(무릎 꿇기는 허벅지를 반으로).
짧은 다리·납작한 몸이 되어 사용자가 빼 달라고 했다. 지금은
* 다리를 들 때 — 반바지 속으로 **밀어 올린다**(ty). 보이는 다리가 짧아질 뿐 모양은 그대로다.
* 무릎을 굽힐 때 — 허벅지·정강이를 **돌린다**(rot). 발을 땅에 붙이면 몸이 알아서 내려앉는다.
* 쓰러짐 — 무릎 꿇기를 빼고 **통째로 옆으로** 넘어간다.

## 달리기 · 주먹 (0.70.26 고침)

* **달리기** — 팔다리를 **앞뒤로**. 앞으로 간 팔은 주먹이 턱 아래까지 올라와 몸 **앞**에 그리고,
  뒤로 간 팔은 손이 엉덩이 **뒤로** 숨는다(`_fore` · `_back`). 앞으로 간 다리는 무릎을 높이 든다.
  **고개를 숙인다**(머리를 16점 내려 턱을 당김). 뒤로 찬 발 뒤에 흙먼지.
* **주먹** — 두 주먹을 턱 아래로 올린 **가드**에서 오른손 잽 → 가드 → 왼손 스트레이트(몸을 틀어 앞을 가로질러) → 가드.
* 팔 자세는 **손을 둘 자리**로 준다(`Body.ik` — 뼈 길이는 그대로, 가슴에 붙은 좌표).
  달리기처럼 크게 흔드는 팔은 각으로 준다 — 손 자리를 이으면 어깨 가까이를 지나 팔꿈치가 옆으로 튄다.

## 어떻게 움직이나

* **조각** — 머리 · 몸통 · 팔 둘 · 다리 둘 · 뒷머리(긴 머리). 팔은 겨드랑이 선(armhole)과
  팔·몸 사이 빈틈으로 가른다.
* **뼈** — 발밑 → 골반 → 허리 → 목, 어깨 → 팔꿈치 → 손, 고관절 → 무릎.
  팔꿈치·무릎 둘레의 점은 두 뼈를 **섞어** 따라가서 꺾이지 않고 휜다.
* **발 붙이기** — 다리를 굽혀도 낮은 발이 늘 땅에 닿게 몸을 내린다(`_plant`). 점프는 `_lift` 만큼 띄운다.
* **가려 있던 곳** — 반바지 속 허벅지(아래로 늘임) · 턱 밑 목 · 겨드랑이 · 팔 뒤 머리칼은
  원래 그림에 없어서 **지어 채웠다.**

## 게임에 넣은 것 (0.70.26)

`tools/body-game.py` 가 몸 넷 × **장면 12** × **층 54** 를 굽는다 → `assets/bodies/<몸>/<층>.webp` · `src/data/bodies.json`.

| 장면 | 크기 | 쓰는 곳 |
|---|---|---|
| `stand` · `walk1` · `walk2` | 160px(들판 2배) | 들판 — 서기 · 걷기 박자(_walkPhase, 예전 _walkKey 와 같은 박자) |
| `bstand` | 320px(전투 4배) | 전투 기본 · 캐릭터 창 · 직업 고르기 칸 |
| `stance_<무기>` · `attack_<무기>` | 320px | 전투 자세 · 때리는 순간. 무기 = sword · bow · staff · fist(맨손) |

층은 `cape_2~4 · base · armor · boots · belt · necklace · gloves · pads · helmet (각 0~4) · weapon_<무기>_<0~4>`.
게임은 `src/core/BodyLook.js` 에서 이 순서로 겹친다. 층마다 **맨몸과 다른 점만** 담았으므로
팔이 갑옷 앞을 지나는 자리는 갑옷 층에 없다 — 겹치기만 하면 앞뒤가 맞는다.
층 그림은 lazy(누가 입을 때만 읽는다) — 몸 넷을 다 읽으면 풀어 놓은 크기가 수백 MB 다.

## 게임에 넣을 때

* 한 장이 **80×80**(게임 크기)이다. 몸은 가운데 아래 48×64 — 둘레는 칼·효과가 나갈 자리다.
  지금 게임 그림(48×64)과 발밑 기준점을 맞춰야 한다.
* 앞모습 하나다. 왼쪽으로 걸을 때는 지금처럼 **좌우 뒤집기**로 간다.
